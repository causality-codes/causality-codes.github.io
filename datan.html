Method

datan — direct principal-value integration

Simpson quadrature on the KK integral with the singularity handled by subtraction. Slow and unglamorous, but it's the ground truth every other method on this site is measured against.

validated kramers_kronig.py scipy.integrate.simpson

The problem

The kernel \(1/(\omega'^2 - \omega^2)\) diverges at \(\omega' = \omega\). Naive quadrature either blows up or, if the grid happens to straddle the pole, returns a value that depends on grid alignment rather than on the physics.

The standard fix is singularity subtraction. Since

$$\mathcal{P}\!\!\int_0^\infty \frac{\mathrm{d}\omega'}{\omega'^2 - \omega^2} = 0$$

we can subtract a multiple of that vanishing integral to remove the pole from the numerator:

$$\varepsilon_1(\omega) - 1 = \frac{2}{\pi}\int_0^\infty \frac{\omega'\varepsilon_2(\omega') - \omega\,\varepsilon_2(\omega)} {\omega'^2 - \omega^2}\,\mathrm{d}\omega'$$

The integrand is now regular at \(\omega' = \omega\), where it takes the finite limit \(\bigl[\varepsilon_2(\omega) + \omega\,\varepsilon_2'(\omega)\bigr]/(2\omega)\). Simpson's rule applies directly.

Edge effects

Direct PV integration on a finite window turns a nonzero baseline into a logarithmically diverging boundary term. This is the dominant error source, not the quadrature.

Three mitigations, applied in order:

  1. Mean-centre \(\varepsilon_2\) before transforming. The Hilbert transform annihilates DC — \(\mathrm{sgn}(0) = 0\) — so the constant contributes nothing but boundary artefacts.
  2. Tukey taper with \(\alpha = 0.2\) to soften the window edges.
  3. Edge-value padding (not zero-padding) for slowly decaying tails. Zeros introduce a discontinuity that is worse than the truncation it was meant to fix.

Convention

The RefFIT KK relation (Eq. 2-17) is written on the half-line \([0,\infty)\) and implies an odd extension of \(\varepsilon_2\). This is a different object from the bare full-line Hilbert transform, which uses an even extension. The two differ by more than a sign — mixing them silently produces wrong spectra.

Usage

from kramers_kronig import kk_simpson

eps1 = kk_simpson(omega, eps2, taper=0.2, pad="edge")

Reference

Named after DATAN (D. B. Tanner), which popularised careful PV quadrature for reflectivity KK analysis in the optical-spectroscopy community.
